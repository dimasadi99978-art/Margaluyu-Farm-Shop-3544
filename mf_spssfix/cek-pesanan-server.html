Cek Server Pesanan

Halaman ini memeriksa apakah /api/orders di Vercel dapat dihubungi (tanpa memuat data pelanggan).

"Gagal terhubung" / "Failed to fetch" itu wajar jika halaman ini dibuka langsung dari file di komputer (alamatnya diawali file://), atau jika website belum dipublikasikan. /api/orders adalah fungsi server yang hanya berjalan setelah situs ini benar-benar online (misalnya sudah dipublikasikan di Vercel). Coba lagi setelah situs online, dan pastikan ORDERS_MASTER_KEY serta ORDERS_BIN_ID sudah diisi di Vercel → Settings → Environment Variables.
