Setup Penyimpanan Testimoni & Pesanan

Halaman ini hanya perlu dibuka satu kali untuk membuat tempat penyimpanan testimoni dan pesanan yang bisa dilihat semua pengunjung web. Setelah selesai, halaman ini boleh diabaikan atau dihapus.

Langkah 1 — Ambil Master Key

Buka jsonbin.io, daftar akun gratis, lalu buka menu API Keys dan salin X-Master-Key Anda. Tempel di bawah ini.

Langkah 2 — Buat Penyimpanan

Klik tombol di bawah ini untuk membuat tempat penyimpanan testimoni baru (hanya sekali saja, jangan diklik berkali-kali agar tidak membuat banyak penyimpanan kosong).

Berhasil dibuat! Salin dua nilai ini ke file testimoni-config.js:

TESTIMONI_MASTER_KEY:

TESTIMONI_BIN_ID:

Langkah 3 — Buat Penyimpanan Pesanan (untuk Lacak Pesanan)

Gunakan Master Key yang sama untuk membuat satu penyimpanan lagi, khusus untuk data pesanan.

Berhasil dibuat! Salin dua nilai ini ke file orders-config.js:

ORDERS_MASTER_KEY:

ORDERS_BIN_ID:

Langkah 4 — Selesai

Buka file testimoni-config.js dan orders-config.js, tempelkan nilai-nilai di atas ke masing-masing file, simpan, lalu upload ulang folder web ini ke hosting Anda. Jangan lupa juga ganti ADMIN_PASSWORD di orders-config.js dengan kata sandi milik Anda sendiri sebelum meng-upload, supaya halaman admin-pesanan.html hanya bisa dibuka oleh Anda.
